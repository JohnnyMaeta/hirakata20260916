まず、今日の3行

職員の先生方に示すなら、これで足ります。判定に迷う仕事が来たときの問いは、1つだけです。

作業は、渡す。　練習は、渡さない。　判断は、渡さない。
迷ったときの問い ——「これは作業か、練習か、判断か」
  • 作業＝繰り返しで、誰がやっても同じ結果になるもの（集計・転記・整形・要約・下書き）→ 渡す
  • 練習＝その人が伸びるためにやっているもの（子どもの学習、若手が経験を積む工程）→ 渡さない
  • 判断＝責任が発生するもの（評定、生徒指導の決定、保護者への回答の最終形）→ 渡さない

3つに分けられない仕事は、たいていまだ分解されていないだけです。分解すると、中に作業が混じっています。

・学年主任に伝えるときに使える言い方で

実演1——所見の叩き台。差がつくのは「文体仕様書」だけです

ノートブックは御市でもお使いになれると伺いました。道具は同じです。差がつくのは、①の「文体仕様書」を作ってあるかどうか、そこ一か所だけだと思っています。下の3つを、この順番で使ってください。

① 文体仕様書をつくる（1回だけ）
これから、私が過去に書いた通知表の所見をいくつか貼ります。

・ほめ方の型（どこを、どういう順番でほめているか）

---（②の出力をここに貼る）---

・3つの柱のうち、記録がある柱だけを書く（ない柱は無理に書かない）
・1人あたり150字以内
・断定しすぎない。事実と、そこから見える成長だけを書く

【子どもの記録】
1番　9月の運動会でリレーの並び順を提案した。9月の理科でグループの記録係。
2番　……
子どもの記録は、出席番号か管理番号に置き換えてから貼ってください。
御市のポリシーには、こう書かれています。
「個人情報が機械学習に利用される場合には、当該個人情報の入力禁止」（枚方市立学校情報セキュリティポリシー 11.4(4)）
「入れるな」ではなく「機械学習に使われるなら入れるな」です。ですので外し方は2つあって、両方やれば二重に外れます。
　1　学習に使われない使い方をする（認められたサービスを、学校のアカウントで）
　2　そもそも個人情報にしない（氏名 → 管理番号・出席番号）
巻末の別表2も、いちどご覧ください。分類IIIの「児童・生徒の学習記録（ワークシート、レポート、作品、振り返り等）」はクラウドで扱えるほうに、分類IIの「通知表・評定一覧表」は教育内部系（校外持ち出し禁止）のほうに入っています。所見の"材料"と"結果"は、別の分類です。
とはいえ、これは市外の人間の読み方です。最終的に判断されるのは校長先生（ポリシー上の校内情報セキュリティ責任者）です。迷ったら必ずご確認ください。
出てきたものは叩き台です。最終形にするのは人間の仕事——「判断は、渡さない」のほうに入ります。

その「毎回貼るのがめんどくさい」が、合図です

3回くらい同じことを頼んだあたりで、貼るのが面倒になります。そうしたら、①②で保存した文章をカスタム指示に移してください。御市では Gemini の「Gem」も Copilot の「エージェント」も使えると伺いました。呼び方は違いますが、同じ役割の機能です。

ここでつまずく人が多いはずです。Gem・エージェントは、ブラウザ版でしか作れません。
ふだんiPadのアプリで生成AIを使っていると、作る画面が出てきません。作るときだけ、ブラウザで開いてください。いちど作ってしまえば、アプリからでも使えます。
御市で使えると伺っているもの（2026年9月時点・大脇班長より）
Copilot（市の推奨）／Gemini（アカデミック利用可）／Geminiノートブック／Canva AI。カスタム指示は Gem・エージェントとも使用可（作成はブラウザ版のみ）。

これが、自分専用AIの作り方の全部です。白紙と戦ってプロンプトを設計しようとすると止まります。チャットで往復して、うまくいったやり方が固まってから、それをカスタム指示に翻訳する。順番が逆だと、作れません。

/**
 * 振り返りフォーム 一式セットアップ
 *
 * 実行するのは setupDemo ひとつだけ。押すと、下の4つが一度にできます。
 *   1. 振り返りフォーム（質問は3つ。出席番号／今日の授業はどうだった？／先生と話したいことは？）
 *   2. 回答スプレッドシート（「フォームの回答 1」シート）
 *   3. 今日の日付のダミー回答18件（実在の子どもは1人も入っていません）
 *   4. 【振り返りダイジェスト】メールが自分宛に1通
 *  ＋ 毎日16時のトリガー（以降、回答があった日の夕方に自動で届きます）
 *
 * 【使い方】script.new で新しいプロジェクトを作って、これを丸ごと貼る。
 * 　　　　　▶実行を押すのは setupDemo です。初回だけ承認画面が出ます。
 * 【あとかたづけ】できたフォームとスプレッドシートを削除すれば、元どおりです。
 *
 * ※ すでに振り返りフォームをお使いの方は、この下半分の sendReflectionDigest だけを
 * 　 回答スプレッドシートの「拡張機能 → Apps Script」に貼れば動きます。
 */

// ▼ 選択肢（フォームの文言を変えたら、ここも合わせる）
const CHOICES = ['4 よくわかった', '3 だいたいわかった',
                 '2 少しむずかしかった', '1 むずかしかった'];

const Q_NUMBER = '出席番号';
const Q_SCORE  = '今日の授業はどうだった？';
const Q_TALK   = '先生と話したいことは？';
const SHEET_NAME = 'フォームの回答 1';
const PROP_KEY = 'DEMO_SS_ID';

/** ★これを実行する。1回押すだけ。 */
function setupDemo() {
  // 1 フォームを作る
  const form = FormApp.create('振り返り（おためし）');
  form.setDescription('今日の授業の振り返りです。1分で終わります。');
  form.addTextItem().setTitle(Q_NUMBER).setRequired(true);
  form.addMultipleChoiceItem().setTitle(Q_SCORE).setChoiceValues(CHOICES).setRequired(true);
  form.addMultipleChoiceItem().setTitle(Q_TALK).setChoiceValues(['ある', 'ない']).setRequired(true);

  // 2 回答先のスプレッドシートを作って結びつける
  const ss = SpreadsheetApp.create('振り返りの回答（おためし）');
  form.setDestination(FormApp.DestinationType.SPREADSHEET, ss.getId());
  PropertiesService.getScriptProperties().setProperty(PROP_KEY, ss.getId());

  // 3 ダミー回答18件
  const dummy = [
    [1, 0, 'ない'], [2, 0, 'ない'], [3, 1, 'ない'], [4, 0, 'ない'],
    [5, 1, 'ない'], [6, 0, 'ない'], [7, 2, 'ない'], [8, 1, 'ない'],
    [9, 0, 'ない'], [10, 1, 'ない'], [11, 0, 'ない'], [12, 2, 'ない'],
    [13, 1, 'ない'], [14, 0, 'ない'], [15, 3, 'ある'], [16, 1, 'ない'],
    [17, 2, 'ある'], [18, 0, 'ない'],
  ];
  const items = form.getItems();
  const numberItem = items[0].asTextItem();
  const scoreItem  = items[1].asMultipleChoiceItem();
  const talkItem   = items[2].asMultipleChoiceItem();
  dummy.forEach(function (d) {
    form.createResponse()
      .withItemResponse(numberItem.createResponse(String(d[0])))
      .withItemResponse(scoreItem.createResponse(CHOICES[d[1]]))
      .withItemResponse(talkItem.createResponse(d[2]))
      .submit();
  });
  SpreadsheetApp.flush();
  Utilities.sleep(3000);

  // シート名が英語（Form Responses 1）で作られることがあるので揃える
  const sheets = SpreadsheetApp.openById(ss.getId()).getSheets();
  if (!sheets.some(function (s) { return s.getName() === SHEET_NAME; })) {
    sheets[0].setName(SHEET_NAME);
  }

  // 4 ダイジェストを1通送る（当日はこのメールを画面に出す）
  sendReflectionDigest();

  // ＋ 毎日16時のトリガー（すでにあれば作らない）
  const exists = ScriptApp.getProjectTriggers().some(function (t) {
    return t.getHandlerFunction() === 'sendReflectionDigest';
  });
  if (!exists) {
    ScriptApp.newTrigger('sendReflectionDigest')
      .timeBased().atHour(16).everyDays(1).create();
  }

  Logger.log('--- できたもの ---');
  Logger.log('フォーム（回答画面）: ' + form.getPublishedUrl());
  Logger.log('回答シート: ' + ss.getUrl());
  Logger.log('メール: Gmailで「振り返りダイジェスト」を検索');
}

/**
 * 集計してメールを送る本体。
 * ※ 回答スプレッドシートの中に直接コードを置く場合は、下の2行を
 * 　 const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(SHEET_NAME);
 * 　 の1行に置き換えられます（このスクリプトは単体で動くようにしてあります）。
 */
function sendReflectionDigest() {
  const id = PropertiesService.getScriptProperties().getProperty(PROP_KEY);
  const bound = SpreadsheetApp.getActiveSpreadsheet();
  const ss = bound || SpreadsheetApp.openById(id);
  const sheet = ss.getSheetByName(SHEET_NAME);
  if (!sheet) throw new Error('「' + SHEET_NAME + '」シートが見つかりません。タブ名を確認してください。');

  const rows = sheet.getDataRange().getValues();
  const header = rows[0];
  const colNumber = header.indexOf(Q_NUMBER);
  const colScore = header.indexOf(Q_SCORE);
  const colTalk = header.indexOf(Q_TALK);
  if (colNumber === -1 || colScore === -1 || colTalk === -1) {
    throw new Error('見出し（質問文）が見つかりません。フォームの質問文を変えていないか確認してください。');
  }

  const today = new Date();
  today.setHours(0, 0, 0, 0);
  const ONE_DAY_MS = 24 * 60 * 60 * 1000;

  const counts = {};
  const talkNumbers = [];
  let total = 0;

  rows.slice(1).forEach(function (row) {
    const stamp = row[0];
    if (!(stamp instanceof Date)) return;
    const d = new Date(stamp);
    d.setHours(0, 0, 0, 0);
    if (Math.round((d - today) / ONE_DAY_MS) !== 0) return;

    total++;
    counts[row[colScore]] = (counts[row[colScore]] || 0) + 1;
    if (row[colTalk] === 'ある') talkNumbers.push(row[colNumber]);
  });

  if (total === 0) return;

  const lines = CHOICES.map(function (c) { return '・' + c + '：' + (counts[c] || 0) + '件'; });
  let body = Q_SCORE + '\n' + lines.join('\n');
  if (talkNumbers.length > 0) {
    body += '\n\n先生と話したい：' + talkNumbers.join('番、') + '番';
  }
  MailApp.sendEmail(Session.getActiveUser().getEmail(),
    '【振り返りダイジェスト】' + total + '件', body);
}

わたしが書いたのは、この文章だけです

当日「お見せしたいのはコードではなく発注文です」と申し上げたのが、これです。AIに貼るのはこの文章で、返ってくるのが次のコードです。ここを読んでいただくのが、いちばん持ち帰りになると思っています。

AIへの発注文
振り返りフォームの回答が入っているスプレッドシートの「フォームの回答 1」シートを集計するGASを書いてください。質問は「出席番号」「今日の授業はどうだった？」「先生と話したいことは？」の3つです。
今日送信された回答だけを対象に、①回答の件数 ②「今日の授業はどうだった？」の選択肢ごとの件数（0件の選択肢も表示）③「先生と話したいことは？」が「ある」だった出席番号 を、1通のメールにまとめて自分宛に送ってください。回答の件数は、件名に入れてください。
今日の回答が1件もない日は、何も送らないでください。
シートが見つからないときは、日本語のエラーメッセージで教えてください。
メールアドレスは私が入力しなくても動くようにしてください。
入れたのは3つだけです。①何が欲しいか ②材料はどこにあるか ③いつ動いてほしいか。
「0件の日は送らない」「0件の選択肢も表示」のような細かいところは、賢さではなく一度動かしてみて足したものです。最初から思いつかなくて構いません。

返ってきたコード

すでに振り返りフォームをお使いの方は、こちらだけで動きます。回答スプレッドシートを開いて「拡張機能 → Apps Script」に貼り、sendReflectionDigest を実行してください。夕方に自動で届けたいときは、時計マークから「時間主導型・日付ベース・午後4時〜5時」のトリガーを1本足します。

    if (!(stamp instanceof Date)) return;
    const d = new Date(stamp);
    d.setHours(0, 0, 0, 0);
    if (Math.round((d - today) / ONE_DAY_MS) !== 0) return;

    total++;
    counts[row[colScore]] = (counts[row[colScore]] || 0) + 1;
    if (row[colTalk] === 'ある') talkNumbers.push(row[colNumber]);
  });

  if (total === 0) return;

  const lines = CHOICES.map(c => `・${c}：${counts[c] || 0}件`);
  let body = '今日の授業はどうだった？\n' + lines.join('\n');
  if (talkNumbers.length > 0) {
    body += `\n\n先生と話したい：${talkNumbers.join('番、')}番`;
  }
  MailApp.sendEmail(Session.getActiveUser().getEmail(),
    `【振り返りダイジェスト】${total}件`, body);
}

推進役の先生がいちばん困るのは、操作ではなく「上に説明する言葉がない」ところだと思っています。説得の言葉ではなく、引用だけを並べた1枚を置いておきます。「これは前多が言っていることではなく、国が公式に決めていることです」と言える形にしてあります。

周りを巻き込むときの3つ

  • まず、あなたが楽になってください。学校には、便利な仕組みを公式業務として維持する仕組みがありません。あるのは作った人の善意だけです。だから全体展開が先ではなく、徹底的に個人仕様で自分を救うのが先。定時で帰る人が一人生まれることが、いちばん静かで強い普及活動です。
  • モチベーションの差は埋めません。埋めるのは「めんどくさい」。「めんどくさい」は業務改善のアンテナです。苦手な先生ほど感度が高い。配るのは手順ではなく、この一言でいいと思っています。
  • 「誰でもできる仕組み」は、先に作ると誰も使いません。1人が自分用に作って回り始めたものだけが、仕組みにする価値を持ちます。仕組み化は成功の後始末であって、導入の入口ではありません。
「プロンプトって命令ですよね。機械に命令なんかしません」と言われたら。
「命令じゃなくて、相談です」「下書きを頼んでいるだけです」と言い換えてみてください。言葉が壁になっているだけ、ということは意外と多いです。

子どもの端末のルール（ご質問1の続き）

  • うちの学校でも遊びます。先進的だから遊ばないのではありません。
  • 遊ぶ原因の多くは端末ではなく、授業デザインと学級経営です。手が空いた時間があるから遊ぶ。端末を取り上げても、手が空いている事実は残ります。
  • 禁止で消えるのは練習の機会です。問題のほうは、監視の届かないところに潜るだけです。
  • 代案は教習所モデル。使わせて、失敗させて、学ばせる。そしてルールは子ども自身に作らせる。「守れなかったらどうするか」まで決めさせます。大人が作ったルールは破る対象になりますが、自分たちで作ったルールは守る対象になります。
  • 制限をかけるな、とは言いません。ただし制限は目的ではなく、練習期間の補助輪です。「いつ外すか」を言わない制限は、そのまま永久化します。
